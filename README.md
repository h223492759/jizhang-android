# 记账本 (jizhang-android)

安卓端记账 App，对接 [jizhang](https://github.com/h223492759/jizhang) 后端 REST API。

## 功能
- 多服务器配置（内网 / 外网地址）、登录、账本切换
- 记一笔：分类选择（支出/收入）+ 自定义数字键盘 + 日期/备注
- 明细：按日分组的流水列表
- 图表：月/年 支出/收入，分类占比
- 账单：月账单 / 年账单
- 预算：年度总预算 + 分类预算进度
- 资产：存款目标（净资产）+ 分类钱包
- 发现：AI 助手（自然语言记账解析、月度分析）
- 自动记账：监听微信/支付宝/云闪付/招行信用卡支付通知，自动解析金额/商户/分类入库
  - 通知监听通道（v1.1 起，稳定）
  - 无障碍兜底通道（v2.0.0 实验）：只监听白名单支付应用的窗口变化，低电耗（约 1%/天）、无 OCR，补齐「支付成功仅在 App 内弹窗、无系统通知」的漏记
- 定期记账：按模板到点自动生成账单
- 离线优先：本地 SQLite 镜像 + Outbox 队列，弱网也能记账，联网自动同步
- 我的：设置、关于、退出登录

## 自动记账双通道去重
通知与无障碍两通道命中同一笔支付时只记一笔：原生队列级（60s 同包同额丢弃、通知优先）+ 应用层跨通道校验（1 分钟内同款同额跳过）；设置页可随时开关任一路通道、退回单通道模式。

## 技术栈
Flutter 3.22 + Dio + Riverpod + fl_chart + SharedPreferences

## 构建
```bash
flutter pub get
flutter build apk --release
```
APK 位于 `build/app/outputs/flutter-apk/app-release.apk`。

## 发布
推送到 `main` 触发 CI 构建；打 `v*` tag 自动发布 GitHub Release（含 APK）。
