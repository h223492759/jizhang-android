# 发布回归清单（v2.4.0 / 网页 v1.2.0 安全部批次）

每次发版后按 4 条主链路各验一遍，全过才算发布成功。以下均在真机 + NAS 环境（192.168.50.50:9600）执行。

## 1. 同步链路

| 步骤 | 预期 |
| --- | --- |
| 我的 → 立即同步 | 状态行显示成功，运行日志出现「[同步] 完成：流水变更 N 条」或「指纹一致，跳过拉取」 |
| 网页端记一笔 → 手机立即同步 | 手机流水页能看到该笔 |
| 手机记一笔（离线 10s）→ 恢复网络同步 | 流水出现在服务器，网页可见 |
| 断网同步 | 运行日志出现「[同步] 失败（网络不可达）」，队列保留不丢 |

## 2. 自动记账入队链路

| 步骤 | 预期 |
| --- | --- |
| 微信/支付宝产生一笔真实支付 | 通知到达后运行日志出现「已入队待处理 <来源> <数值> | <完整原文>」 |
| 入队后 2~3s | 弹出自动记账预填卡片（金额/分类/支付方式正确） |
| 确认后 | 流水落库并随下次同步上云 |

## 3. 定期记账生成链路

| 步骤 | 预期 |
| --- | --- |
| 打开定期记账页 | 模板列表正常，「下次」日期按严格未来显示 |
| 到期模板点「生成到期记录」 | 生成一笔流水，同周期重复点击不重复生成（last_period 防重） |
| 删除生成的定期流水 | 未来日期 → 回退可重新生成；已到日期 → 不回退 |

## 4. 回收站删除回退链路

| 步骤 | 预期 |
| --- | --- |
| 流水详情 → 删除 | 进回收站（/api/flows/trash 可见，含 deleted_by/deleted_at） |
| 回收站恢复 | 流水回到列表，字段完整 |

## 5. 本批次专项（安全修复）

| 步骤 | 预期 |
| --- | --- |
| 安装本版 APK（覆盖安装旧版） | 不要求卸载，数据保留 |
| 同步指向 http://192.168.50.50:9600 | 正常（明文白名单内） |
| 同步指向其他公网 http 地址 | 请求被系统明文策略拦截（符合预期，HTTPS 正常） |
| 登录页连续输错密码 10+ 次 | 返回「失败次数过多，请 15 分钟后再试」 |
| adb backup 尝试备份 | 不弹出备份确认（allowBackup=false） |
